# Kelpo — product writing rules

Every string a user reads is product work. Write like a person describing what the
thing does, with real nouns and real verbs. Never write marketing filler.

## Banned (AI slop)

seamless, effortless, elevate, empower, unlock, revolutionize, game-changing,
cutting-edge, robust, leverage, delve, transform, supercharge, streamline,
hassle-free, "say goodbye to", "in today's fast-paced world", "look no further",
"the perfect solution", "take it to the next level", "user-friendly",
"easy-to-use", "powerful", "innovative", "world-class", "best-in-class",
"unparalleled", "simply", "just".

## Rules

1. Name the behaviour: "Download all originals (.zip)", not "Get files".
2. Use numbers and dates: "Ends 27 Nov, 09:41", not "Expires soon".
3. State the tradeoff honestly: "Previews are light. Downloads are the real files."
4. Talk about the sender's actual job: finals, client delivery, WhatsApp, originals.
5. Short sentences. No exclamation marks in UI copy.
6. The recipient never sees product jargon like "link", "upload", "capability".
